# 宝宝识字台

一款为 4 岁左右小朋友设计的**识字启蒙工作台**。单文件网页，手机、平板、电脑都能直接用，无需安装、无需联网（离线也可用）。

在线体验：https://yydshy.github.io/baobao-shizi/

---

## 它能做什么

- **每日 5 个字**：每天自动出一批字（数量家长可调 1–18），昨天没学完的字会顺延到今天。
- **象形字翻卡（单张轮播）**：一次只展示一张字卡，左右箭头 / 底部圆点 / 手指滑动切换。点卡片翻面看手绘象形图、拼音和释义；点小喇叭听标准普通话朗读（先读字再读拼音）。
- **组词练习**：看大字，从几个选项里选出正确的词，答对得星星，答错不惩罚、鼓励再试。
- **闯关积分**：星星累计成进度环，每 10 颗星升一关；孩子可申请用星星兑换奖励，家长确认后成交。
- **庆祝动效**：认识字、答对、完成今日、兑换成功都会撒彩色纸屑。
- **离线可用**：内置 Service Worker，平板断网也能照常打开。
- **字库**：共 36 个字（含数字一~八、十），每字带分类（自然 / 人体 / 动物 / 数字 / 生活），全部为内联手绘 SVG 象形图。

## 两种模式

| 模式 | 给谁用 | 说明 |
|------|--------|------|
| 孩子模式 | 小朋友 | 大字体、大按钮、鲜艳配色，直接认字、练习、攒星星 |
| 家长模式 | 家长 | 4 位密码锁（首次进入设置），负责发任务、管理奖励、确认兑换、字库预览 |

家长模式顶部有「今天要处理」列表，列出待确认的兑换申请（逾期会标红）。

## 怎么用

1. 用浏览器打开在线链接，或把本仓库的 `index.html` 直接双击打开。
2. 首次进入家长模式会让你设 4 位密码，设好后告诉家里人即可。
3. 想当 App 一样用：手机浏览器打开后「添加到主屏幕」（iPhone 用 Safari 分享菜单，安卓用 Chrome 的 ⋮ 菜单），以后从桌面图标点开就是全屏体验。

## 数据说明

- 所有学习记录、星星、兑换记录都存在**浏览器本地（localStorage）**，不上传任何服务器。
- 换设备 / 换浏览器需要重新来过，可点首屏右上角「导出」保存一份 JSON 备份，到新设备「导入」迁移。
- 公开链接谁都能打开，但页面不预填任何隐私数据，家长密码只是防小朋友误触，请勿用于存放真实敏感信息。

## 技术栈

- 纯 HTML / CSS / JavaScript，**零外部依赖、零外链**，整个应用内联在一个文件里。
- 发音朗读使用浏览器原生 `SpeechSynthesis`（依赖系统中文语音包，手机/平板一般自带）。
- 离线能力由 `sw.js`（Service Worker）提供，缓存策略为网络优先、断网回退缓存。
- 状态持久化使用 `localStorage`（键名前缀 `wb_shizi_`）。

## 目录结构

```
.
├── index.html   # 全部前端代码（HTML + CSS + JS 内联）
├── sw.js        # Service Worker，提供离线缓存
└── README.md
```

## 部署到自己的 GitHub Pages

1. Fork 或克隆本仓库。
2. 确保 `index.html` 位于仓库根目录。
3. 在仓库 Settings → Pages 中，Source 选择 `main` 分支、目录 `/`。
4. 稍等片刻即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。

如果要更新字库或调整默认每天字数，编辑 `index.html` 中的 `LIB`（字库）与发布任务逻辑后重新推送即可。
